WEB DESIGN BASICS

Seven Key Concepts

These terms help explain how modern websites are built.

1. HTML

HyperText Markup Language structures webpage content using elements such as headings, paragraphs, images, and links.

2. CSS

Cascading Style Sheets controls the presentation of HTML, including colors, typography, spacing, and layout.

3. DOM

The Document Object Model represents a webpage as a structured set of objects that scripts can access and modify.

4. Responsive Design

Responsive design adapts a website's layout and content to different devices and screen sizes.

5. CSS Grid

CSS Grid is a layout system that arranges content in rows and columns.

6. Flexbox

Flexbox arranges items along a row or column and helps distribute available space between them.

7. Accessibility

Accessibility means designing and developing websites so people with different abilities can use them. Descriptive links, image alt text, and semantic HTML are examples of helpful practices.

How These Concepts Work Together

HTML provides the content and structure. CSS controls the appearance and layout. The DOM represents the document in a way scripts can interact with. Responsive design, Grid, and Flexbox help the layout adapt to different devices, while accessibility helps make the site usable by more people.
