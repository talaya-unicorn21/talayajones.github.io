CSS and Visual Design

CSS makes a webpage visually appealing and easier to navigate.

What Is CSS?

CSS stands for Cascading Style Sheets. It controls how HTML elements look, including their colors, fonts, sizes, spacing, borders, and positions. Keeping styles in a separate file also makes it easier to maintain a consistent design across several pages.

Three Types of CSS Selectors

Element Selector

Selects every element with a particular HTML tag.

p {
    color: #555555;
}

Class Selector

Selects elements that share a class name.

.highlight {
    background-color: #f8e8ed;
}

ID Selector

Selects the element with a specific ID.

#main-title {
    color: #a34f6a;
}

Important Styling Properties

  • Color: Changes text color.
  • Background-color: Sets an element's background.
  • Font-family: Determines the typeface.
  • Padding: Adds space inside an element's border.
  • Margin: Adds space outside an element's border.
  • Border: Draws an outline around an element.

Layout with CSS Grid and Flexbox

CSS Grid is useful for arranging content in rows and columns. Flexbox is useful for arranging items in a row or column, such as the navigation links at the top of this website.

Both approaches help create organized layouts without needing to position every element manually.

Hover Effects

A hover effect changes the appearance of a link or another element when a visitor moves a mouse pointer over it. Try hovering over the navigation links or cards on this site.

Responsive Design

Responsive design allows a website to adapt to different screen sizes. CSS media queries can change the layout on smaller devices so that content remains readable and navigation is easier to use. 

@media (max-width: 700px) {
    .card-grid {
        grid-template-columns: 1fr;
    }
}
