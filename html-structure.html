HTML and Website Structure

HTML provides the foundation and structure of a webpage.

What Is HTML?

HTML stands for HyperText Markup Language. It uses elements to organize content such as headings, paragraphs, images, links, lists, and tables. Browsers read HTML to determine how content is structured.

Common HTML Elements

  • <h1> defines a main heading.
  • <p> defines a paragraph.
  • <a> creates a hyperlink.
  • <img> displays an image.
  • <ul> and <li> create a list.
  • <table> organizes information into rows and columns.

Semantic HTML

Semantic HTML elements describe the purpose of a section. For example, <header> identifies introductory content, <nav> identifies navigation, <main> identifies the primary content, and <footer> identifies footer information.

Semantic elements make code easier to understand and can help assistive technologies interpret the page.

HTML Compared with CSS

Different roles in website development

Example of HTML

<article>
    <h2>My First Article</h2>
    <p>This is an example of webpage content.</p>
    <a href="index.html">Return Home</a>
</article>

The article element groups related content. The heading identifies the topic, the paragraph provides information, and the link allows the visitor to navigate.
